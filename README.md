# Вместе

Простой бюджет на двоих. Сумма, категория, и предупреждение, если месяц уходит быстрее плана.

Пока в папке нет ключей Supabase, бюджет живёт только в этом браузере. Общий вход для двоих включается отдельно, бесплатно.

## Запуск у себя

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. С телефона в той же Wi‑Fi сети можно открыть сетевой адрес из терминала.

На экран «Домой»: в Safari «Поделиться → На экран Домой», в Chrome «Добавить на главный экран».

## Общий бюджет

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. SQL Editor → вставьте `supabase/schema.sql` → Run.
3. Authentication → Providers → Email включён.
4. Authentication → URL Configuration. Добавьте адреса, с которых открываете приложение:
   - `http://localhost:5173`
   - адрес Vercel, когда он появится
5. Скопируйте `.env.example` в `.env` и впишите Project URL и anon key. Это публичный ключ, доступ к чужим бюджетам закрыт правилами в базе.
6. Перезапустите `npm run dev`.

Первый человек входит по почте и создаёт бюджет. В шапке, в названии бюджета, лежит код. Второй входит со своей почты на своём телефоне и вводит этот код. Письмо со ссылкой нужно открывать на том же телефоне, где его запросили.

## Выложить бесплатно

Ключи `VITE_…` попадают в сборку, их нужно задать до `npm run build`.

```bash
npx vercel
```

На Vercel те же две переменные добавьте в настройках проекта и пересоберите. Отдельный домен не нужен: хватит адреса `*.vercel.app`. Его же добавьте в URL Configuration у Supabase.
