Privacy policy

LinkPick is a menu-bar utility for the Mac. It shows a menu and opens a link in the browser or profile you pick. It does not load the web page itself.

Links are not written to disk and are not sent anywhere. There is no account, no analytics, and no advertising. A remembered site stores only the domain, for example example.com, without the path or the query.

To list profiles for Chrome, Edge, Brave, Vivaldi, or Chromium, the app reads the Local State file in a folder you choose. It uses the profile name and email when that file contains them. History, cookies, and passwords are not read.

The helper script linkpick-open.sh stays on your Mac and runs locally. A Mac App Store app cannot pass a profile argument to the browser by itself.

Политика конфиденциальности

LinkPick — утилита для строки меню на Mac. Она показывает меню и открывает ссылку в выбранном браузере или профиле. Саму страницу программа не загружает.

Ссылки не записываются на диск и никуда не отправляются. Нет аккаунта, аналитики и рекламы. Запомненный сайт хранит только домен, например example.com, без пути и без параметров.

Чтобы показать профили Chrome, Edge, Brave, Vivaldi или Chromium, программа читает файл Local State в папке, которую вы сами указали. Из него берутся имя профиля и почта, если они там есть. История, cookies и пароли не читаются.

Скрипт linkpick-open.sh остаётся на вашем Mac и запускается локально. Программа из App Store не может сама передать браузеру аргумент профиля.
